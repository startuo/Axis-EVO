# 对话与任务

Axis-Evo 默认以对话开始。模型回复、拟执行操作、工具结果和独立验收分别呈现；聊天文字不会授予执行权限。

## 开始使用

按 [启动说明](WORKBENCH_SETUP.md)准备并启动 Runtime，直接打开 `http://127.0.0.1:8765`。`--open-browser` 为可选便利功能，打开同一地址。首页直接呈现对话，刷新、多标签、浏览器重启、会话过期和服务重启均不需要会话代码或授权链接。连接初始化与工具审批相互独立。

在“模型设置”选择 DeepSeek，输入 API Key，测试连接，再选择模型并开始对话。Windows 将密钥交给当前用户的原生凭据管理器，页面不会保存可读密钥。连接成功只说明端点响应，不代表后续每个计划都有效。已有高级端点与版本历史保持可用。

## 演示 A：自然对话

在输入框选择“对话”，发送“你能做什么？”。主区显示实际模型返回文本，无文件计划、TaskSpec、Run 或工具批准。模型自述始终是未验证内容，当前模型配置可在模型设置核对。

## 演示 B：文件修改

选择后台已配置的文件任务模板，在一次性工作区提出“将 timeout=10 改为 timeout=20”。查看拟替换片段和目标路径；必要时展开完整参数、Skill 和模型快照。只对审阅过的操作点击一次批准。后端将按钮绑定精确 Plan SHA-256，重复点击不能重复消费。

工具活动以紧凑行显示，展开可读输入和已提交输出。最终是否完成由实际 Core 终态和独立 Acceptance 决定。文件内容或 `patch_file` 返回成功本身不能替代验收。“查看证据”保留摘要、事件序列、意图/结果、文件观察、Checkpoint 和 Recovery 关系。

管理员可另外配置明确的纯读取策略；页面会在发送前展示精确路径范围。只有整个计划均为授权路径的 `read_file` 且新规划进程正常退出时才按策略批准。默认没有此权限，混入写入仍拒绝。详见 [读取策略](WORKBENCH_SETUP.md#可选的明确读取策略)。

## 演示 C：Skill 演化

在“Skills 与演化”依次查看来源版本、模型修订、不可变候选、SHADOW 评估、Gate、批准晋升和首选激活。候选创建、晋升、激活是不同批准，不能用一次操作替代。使用已激活版本创建后续任务，其执行仍单独审阅精确 Plan。

界面默认解释过程，详情可查 Card/Revision/Gate 摘要、配对试验和历史。封闭样例通过不等于通用能力改善；历史失败不删除。既有 TRUSTED 版本的路由回退不会改变历史 Run。

## 演示 D：中断与不确定结果

打开一次性实验环境中已验证的硬退出记录。界面明确显示结果未能确认，仍能查看已提交意图、缺失结果、观察到的文件变化及 Worker 退出。变化不证明具体工具因果，结果缺失也不证明未执行；不要自动重放。

本地审查材料提供实际 `os._exit(70)` 用例、Web 服务存活检查、重启和不重复派发断言。不要在个人真实文件上注入崩溃。恢复子 Run 的结果独立于原始 Source 的 UNKNOWN。

验证环境、离线与真实 Provider 的区别、限制和结果见 [TEST_RESULTS.md](TEST_RESULTS.md)。

## 五至十分钟毕业演示

1. **自然对话，1–2 分钟**：核对当前模型，提一个普通问题并追问，展示真实回复和历史；说明模型文本不是执行事实。
2. **批准文件任务，2 分钟**：使用一次性项目的 config.txt，将 timeout=10 改为 timeout=20。展示替换预览，只批准一次；核对实际文件、Core COMPLETED 和独立验收。
3. **Skill 演化，2–3 分钟**：展示来源 Card、不可变 Candidate、SHADOW、完整配对 Trial、Gate、晋升、激活，随后用该准确版本完成一个新任务。模型耗时较长时可以打开已完成的真实产品记录，并明确其来源。
4. **Inspector，1 分钟**：打开上一步记录，解释 Tool Intent、Tool Result、验收及版本身份，区分 Web 调度状态和 Core 终态。
5. **中断，1 分钟**：打开隔离实验中已验证的 UNKNOWN 记录，展示意图已提交、结果缺失、观察与退出事实；刷新或重启后仍不自动重派。不要在真实文件上制造故障。

演示前确认 Provider 及管理员网络路由仍有效，并准备一次性文件项目；演化夹具和有限真实样例都不能替代正式论文实验或证明泛化收益。
